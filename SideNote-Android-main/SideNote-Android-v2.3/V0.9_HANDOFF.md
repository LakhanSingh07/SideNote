# SideNote v0.9 – Multi-card + theme source handoff

## Implemented in source
- More than one floating note at a time, identified by note ID. Floating and minimizing one card no longer deletes other card windows.
- Per-card drag, minimize, restore, close; last screen position maintained during minimize/restore within current service session.
- Main app and overlay use shared System/Light/Dark palette configuration. Theme preference is persisted; restart overlay after changing theme.
- Theme-aware text for note editors and floating sidebar; main cards switch to dark surfaces in dark mode.

## Deliberately not claimed
- **No APK build, Android runtime tests, or device validation** performed. Kotlin compile has not been proven.
- No on-device performance confirmation. Multi-card positioning is not persisted across service restarts.
- No automated pixel-perfect screenshot comparison against approved concept. Some system UI controls retain native appearance.
- On certain device/secure screens, Android can hide overlays; user note data is still stored separately.
- Multi-window editor behavior and keyboard interaction require physical device testing.

## Acceptance tests for Antigravity
1. Build with JDK 17 / Android SDK 35, run lint and Android tests; fix actual diagnostics.
2. Create 3 notes. Float all 3. Drag to different positions, minimize middle card, restore; others stay visible.
3. Close one card; remaining two stay visible. Reopen same note from sidebar; no duplicates.
4. Switch System/Light/Dark themes; restart sidebar; verify panel, editor, note cards, main activity and system status/nav bars visually.
5. Edit text in overlay with keyboard open; change apps, lock/unlock; check no data loss and no leaked windows.
6. Test overlay permission denial/revocation, protected screens, and foreground service notification on Android 10, 13, 14, 15, 16.
7. Test low-memory service termination, long note scrolling, empty backup, Unicode text, large checklists, reminders, notification denial, import/export.
8. Validate accessibility: touch targets >=48dp, TalkBack labels, text scaling, contrast and reduced motion.

This is a **source milestone**, not a signed release artifact.
