# SideNote v2.2 targeted source audit

## Confirmed changes
- Introduced `safeNotes()` for overlay-only reads to avoid uncaught `IllegalStateException` from corrupted stored notes.
- Refreshed floating cards no longer crash solely due to unreadable JSON data.
- Overlay list rendering aborts instead of misrepresenting a damaged store as empty.
- Preserved original notes data: the save path remains strict and refuses to overwrite corrupt source data.
- Updated Android package versionCode and source versionName.

## Not verified
- No Kotlin/Android compile or device launch was completed in this environment.
- This is a scoped source patch, not evidence that earlier UI/UX or app functionality works.

## Antigravity acceptance steps
1. Open this directory as Android Studio project, sync Gradle, execute `:app:assembleDebug`.
2. Install on Android 13, 14, 15 and 16 if available.
3. Test permissions, edge docking, create/edit, keyboard, six simultaneous cards, drag, minimize, restore, lock/unlock and service restart.
4. Test corruption of a note entry in a development installation; overlay should refuse unsafe reads without deleting original data.
5. Check notifications and reminder trigger/cancellation, import/export and Play policy treatment of overlay and special-use foreground services.
6. Compare screenshots to the approved design; do not claim pixel parity without inspection.

STOPSHIP: any failed build, data loss, crash, or broken basic floating note interaction.
