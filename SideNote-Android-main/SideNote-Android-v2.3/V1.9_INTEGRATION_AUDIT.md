# SideNote v1.9 — Integration safety pass

Based on original v1.8 source (all app sources retained).

## Implemented patches
- Read corrupted notes JSON as an explicit failure, not an empty database; prevents silent data overwrite.
- Reject oversized backup imports (>8 MB, >10,000 notes, excessive title/body/ID sizes) before writing.
- Use a set for backup ID replacement instead of repeated scans.
- Reject stale early reminder broadcasts when their target time is still in the future.

## Scope / validation
- ZIP integrity, Kotlin source presence, XML well-formedness, static regression checks verified.
- Not compiled using Android Gradle Plugin; no APK, no emulator/device testing.
- UI visual fidelity, animation physics, overlay state/restoration and Android system restrictions remain unverified.

## Antigravity first pass
1. Import project and run :app:assembleDebug with JDK 17 and Android SDK 35.
2. Fix any compile errors in source rather than bypassing features.
3. Create 5 notes, swipe edge handle, open six cards, drag/minimize/restore/edit; verify autosave and keyboard.
4. Lock/unlock and restart app and phone; inspect overlay restoration and service behavior (OS restrictions expected).
5. Export/import backup, validate data preservation on invalid JSON, test large import rejection.
6. Set/edit/delete a reminder and ensure no stale reminder fires.
7. Validate contrast, touch targets, fonts and interactions against approved reference screens; record screenshots.
8. Report issues with reproductions and logs. Do not mark release ready without actual device checks.
