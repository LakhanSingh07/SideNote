# SideNote v1.1 — source quality pass (not an APK release)

## Changes applied
- Preserves and refreshes a floating card after its note is edited, using latest disk data.
- Drag handle edge snapping when close to the screen edge.
- Handle, panel and card creation catch WindowManager failures instead of crashing without context.
- Importing a backup with an existing note ID uses the imported note instead of silently retaining the old note.
- Updated version metadata to 1.1.0-source.

## Tests that must be run in Antigravity / Android Studio
1. Compile debug with Android 35 SDK and JDK 17; resolve any compiler errors before further UI claims.
2. Grant overlay permission and launch sidebar; deny and revoke permission while running.
3. Open three independent note cards; drag, snap, minimize, restore and close independently.
4. Edit a floating note; save; verify updated body appears in the existing card at the preserved position.
5. Test edits during lifecycle pause, lock/unlock, service stop and keyboard open/close; ensure no data loss.
6. Test full-dark mode and system toggle with existing cards.
7. Import same backup twice; verify one entry per ID and updated values.
8. Test focus interactions and accessibility via TalkBack on Android 12–16, different densities, and at least Samsung, OnePlus and Pixel.
9. Test overlay restrictions on permission dialogs, secure screens and apps that explicitly block overlays.

## Known gaps
- NOT pixel-perfect to design concept. Modernizing all twelve screens remains work.
- No verified native build or tested APK provided.
- UI uses programmatic Android Views, not an implemented Compose design system.
- Card positions are not persisted across process death; Android may remove overlay windows.
- Reminder scheduling and billing/play-release readiness need native testing.
