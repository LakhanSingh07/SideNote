# SideNote product plan

## Target audience
Students reading lessons, professionals copying reference text across apps, small sellers replying to customer chats, and multitaskers who frequently switch applications.

## Core promise
Save a small thought and access it with one touch without losing your place. A persistent *saved note* is the guarantee; a persistent *overlay* is best effort under Android restrictions.

## Design direction
Editorial-soft utility. Ink #1C202E, lilac #694EE7, warm yellow/pink/mint/blue cards. Fast 120–220ms feedback, large hit targets, easy collapsible handles, never block the whole screen unnecessarily. Respect dark and high-contrast themes in subsequent iteration.

## Validated problem themes (public competitor review sample)
1. Overlay disappears after unlock.
2. Note windows cover content.
3. Long note scrolling / resizing and editor consistency.
4. Quick shortcuts are unreliable on some devices.
5. Users value checklists, rapid retrieval and non-punitive basic tier.
These are qualitative themes, **not** a census of all competitors' reviews.

## MVP success metrics (future measurement, user-consented and privacy-safe)
- New user completes first note and opens an overlay within 3 minutes.
- >95% successful note saves across supported devices.
- User can recover all notes after force stop and relaunch.
- 7-day return rate is validated before payment testing.

## Release gates
- Gate 1: Build and Android device verification (NOT YET PASSED).
- Gate 2: Functional flows on API 26, 33–35.
- Gate 3: OEM compatibility with documented limitations.
- Gate 4: Play foreground service/permission policy review, privacy statement, release signing.
