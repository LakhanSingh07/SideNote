# SideNote v2.1 — Targeted integration patch

Built from the supplied v2.0 source package.

## Changes
- NotesStore now rejects malformed individual note entries instead of silently skipping them, protecting the original database from a subsequent destructive rewrite.
- ReminderReceiver handles an unreadable local store without crashing the broadcast.
- Deleting a note now cancels its scheduled alarm.

## Validation executed
- Package files present, structural assertions of three edits passed.
- AndroidManifest.xml parsed as XML.
- ZIP archive integrity tested.

## Unverified — Antigravity
- Gradle/Kotlin compilation and installation.
- Overlay service lifecycle, cards, focus/keyboard, lock/unlock, OEM restrictions.
- Persisted-data migration, backup import/export, reminder delivery, accessibility and visual fidelity.

**Do not call this a release-ready app before the full native acceptance tests.**
