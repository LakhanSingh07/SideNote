# SideNote v1.5 — onboarding and usability consolidation

## Implemented
- First-run onboarding with three clear steps; explicitly optional overlay permission; guided Android permission deep-link.
- Permission status display and repeatable getting-started guide in main settings area.
- Search, filter and note cards now expose explicit screen-reader descriptions and focusability.
- Appearance settings: dock checkbox uses theme-aware contrast; finishing opacity adjustment requests overlay appearance refresh.
- Existing v1.4 functionality retained; this is not a Compose rewrite or a pixel-perfect visual overhaul.

## Not completed / release gates
- Gradle/Android SDK compile has NOT been executed in this environment.
- No verified APK, emulator, or device results.
- Premium spring physics and 12-screen visual design fidelity remain incomplete.
- Onboarding explicitly does not auto-start an overlay without user action.

## Antigravity test checklist
1. Clean install: tutorial -> permission settings -> continue -> tap Open sidebar.
2. Deny overlay: continue and edit notes without crash.
3. Relaunch: onboarding should not reappear, guide should be reopenable.
4. Change dark/light theme and opacity with overlay open and cards visible.
5. Use TalkBack: search, tabs, note cards and setup permission have readable labels.
6. Rotate screen / change font scale to 200%; verify no clipped actions.
7. Test service lifecycle on Android 13/14/15+ OEM devices and secure screens.
8. Complete compile and Android lint, fix any errors, and test actual Android runtime.
