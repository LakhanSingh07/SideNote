# SideNote v1.6 — Interaction pass

## Source changes
- Animated minimize and restore using a morph-out/recreate sequence that retains window position.
- Edge magnetic snapping animates horizontally instead of abruptly teleporting.
- Cancels active view animations before removing floating windows; reduces callbacks acting on detached windows.
- Improved entrance easing for cards.

## Honest limitations
- Android build, lint, emulator, and physical-device tests were not run in this environment.
- This patch does not implement the entire 12-screen design concept or a physics-spring engine.
- Drag bounds use display metrics; foldable displays, IME, cutouts, multi-window and gestures need real-device validation.
- Foreground services, overlay permissions, background survival and notification behavior must be verified for each supported Android version.

## Antigravity release gates
1. Compile with Gradle and fix all compiler and lint failures.
2. On device: create note, float it, minimize, restore, drag to each edge, check position retention.
3. Tap control buttons during drag and animation; verify no ghost windows or crashes.
4. Test overlay permission denied/revoked, keyboard focus, lock/unlock and service restart.
5. Test multiple simultaneous cards in light and dark modes.
6. Run accessibility/TalkBack, font-scale, landscape and small-screen tests.
7. Verify backup restore and reminder notifications end-to-end.
