# SideNote v2.3 — Clean integration handoff

## Changes from v2.2
- Removed accidentally packaged duplicate v2.1 directory; one canonical Android project root.
- Fail closed on invalid local note field types and oversized note content. Original local data is preserved rather than silently discarded.
- Reject duplicate IDs and malformed text field types in imported JSON backups.
- Android 13+ reminders check notification permission before posting.

## Deliberately not claimed
- Kotlin/Gradle compilation, emulator tests, physical device testing, pixel-perfect screen parity and Play release eligibility are NOT verified.

## Antigravity acceptance sequence
1. Open this project in Android Studio using JDK 17 and Android SDK 35.
2. Run `gradle :app:assembleDebug` (or Gradle wrapper once generated). Fix errors with a log of each change.
3. Install on a real Android phone. Grant overlay permission only when prompted.
4. Create 3 notes; make 2 float; drag and minimize independently; edit and confirm updated text appears.
5. Lock/unlock, force-stop/restart, rotate, open keyboard, and test small screen and dark theme.
6. Export backup; test importing a valid one and deliberately malformed JSON. Confirm existing notes are preserved.
7. Test notifications on Android 13+ with permission allowed and denied.
8. Record screenshots and defect list. Do not approve Play Store release without full acceptance.
