# v0.9.3 — Trusted device allowlist (experimental)

- Added persisted device UUID allowlist and friendly names in SQLite.
- Enforced allowlist on both LAN server and client before encrypted changes exchange.
- Added settings screen to view own UUID, register peer UUID and remove it.
- Existing notes and sync-bundle semantics remain unchanged.

## SECURITY LIMITATION — NOT PRODUCTION-READY
The shared secret is still a global symmetric key. Remote Hello device ID is a claim, not a cryptographically bound device identity. A party with the shared key could impersonate an allowlisted device. Removing a device does not revoke a leaked key or forcibly disconnect an existing session. Rotate key, restart listener and use real per-device public-key mutual authentication with explicit pairing approval before releasing sync. Device IDs must be exchanged over a trusted channel.
