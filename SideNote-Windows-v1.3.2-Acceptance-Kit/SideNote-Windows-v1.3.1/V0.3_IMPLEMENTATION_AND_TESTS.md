# SideNote Windows v0.3 — desktop placement and shortcut update

## Source changes
- SQLite `note_windows` table stores each floating note window's logical coordinates and expanded dimensions.
- `save_window_placement` and `get_window_placement` native Tauri commands added.
- Reopening an existing note restores saved placement, clamped to a currently available monitor.
- Minimizing a note persists its expanded placement; restoring from a chip returns to saved dimensions/position.
- A window-move listener debounces persistence, and window-close persists expanded position.
- Corrected mixed physical/logical pixel handling for edge window positioning.
- Main manager shortcuts: Ctrl+Shift+N = new note; Ctrl+Shift+E = open edge deck. These are **manager-scoped** shortcuts, not global hotkeys.

## Known issues / limitations
- Rust compilation and browser runtime were **not verified** because `cargo` is not available and npm dependencies could not be resolved from offline cache.
- Existing edge tab hover, native floating window, and tray functionality remain unverified.
- Multi-monitor clamping uses logical pixels; test mixed scaling, negative monitor coordinates, and monitors removed while app runs.
- `persistPlacement` movement callback currently persists a 300x300 expanded size for default notes; freeform note resizing is not implemented yet.
- No global keyboard shortcuts, startup integration, autostart, Windows installers, or Android sync are implemented yet.
- Synchronization is **not available**; no QR scan or account required for standalone operation.

## Windows acceptance sequence
1. Install Rust MSVC, Node.js LTS, VS C++ build tools, Windows WebView2.
2. `npm install`, `npm run build`, `npm run tauri dev`, `npm run tauri build`.
3. Open manager, create 3 colored notes, launch edge deck, test hover expand/collapse.
4. Open note, drag from header, close, reopen; verify same position.
5. Minimize, restore, confirm original position and size; repeat 30 times.
6. Test Ctrl+Shift+N and Ctrl+Shift+E in manager with text input focused and unfocused.
7. Connect secondary monitor at different DPI, move note to second monitor, restart, then disconnect monitor and reopen note; confirm visible window.
8. Quit and restart; verify all notes persist and system tray restores main window.
9. Inspect Windows console, app logs, and screenshots; record PASS/PARTIAL/FAIL for each test.
