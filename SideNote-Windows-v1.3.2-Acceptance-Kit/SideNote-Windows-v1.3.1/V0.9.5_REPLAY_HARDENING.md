# SideNote Windows v0.9.5 — In-session replay hardening

## Changes
- Reject duplicate XChaCha20-Poly1305 packet nonces within an inbound TCP session (after authentication).
- Introduced per-session nonce tracking for both listener and client.
- Added a regression test which sends an identical encrypted frame twice.

## Important scope limitations
- This is **not** cryptographic device pairing or full cross-session anti-replay protection. Shared-key device ID impersonation remains possible if the key leaks.
- Secure per-device identity, mutual key authentication, safe device revocation, authentication transcript binding, transport protocol review, Android integration, and real two-PC tests are release blockers.
- Rust and Windows compilation were not executed in this environment. Do not deploy experimental LAN listener with untrusted networks or expose its port outside LAN.
