# SideNote Windows v0.2 — Source Handoff

## Implemented in source
- Collapsible narrow desktop edge rail with note-color tabs and a scrollable pop-out deck.
- Hover-to-open, delayed pointer-leave collapse, and click-to-toggle.
- Repositions edge window to the monitor right boundary when resizing.
- Native tray menu (Open, Quit) and double-click-to-open main window.
- Smaller 110px minimized chip.
- No remote Google Fonts dependency; system font fallback.
- Existing local SQLite notes, pin/archive, colorful floating windows preserved.

## Known limitations
- No Windows compilation/runtime validation; Rust toolchain unavailable.
- Floating note editing saves by explicit Save, not per-keystroke.
- Tray click behavior and window permissions need Windows integration test.
- Edge deck is a native overlay window; hover/resize movement needs DPI/multi-monitor and auto-hide acceptance.
- Note window positions currently not persisted; no global shortcut yet.
- No Android↔Windows synchronization yet.
- Existing delete operation is hard-delete, unsuitable for sync; schema migration and tombstones required before sync.
- No compiled exe/msi.

## Acceptance on Windows
1. Cargo + npm install then `npm run tauri build`; fix compilation errors.
2. Open Edge Deck: collapsed 45px colored rail along right edge.
3. Hover: temporary 244px wide panel; mouse leaves and collapses after ~380ms.
4. With 10+ notes deck scrolls independently.
5. Click preview: opens independently draggable floating note; edge collapses.
6. Minimize note to 110px chip and restore; no duplicate window.
7. Closing manager window / tray controls verified.
8. Restart: notes preserved in SQLite.
9. Test 100%,125%,150% scaling + two displays.
