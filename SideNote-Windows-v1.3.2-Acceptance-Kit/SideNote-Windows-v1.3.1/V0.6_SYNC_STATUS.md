# SideNote Windows v0.6 — Offline Change Exchange (Experimental)

## What is implemented
- Versioned JSON change bundles exported from the existing durable local change log.
- SQLite-imported-change cursor tracking to avoid replaying identical remote entries.
- Atomic import in a database transaction; malformed records abort and roll back the entire bundle.
- Existing note conflicts preserved in `sync_conflicts`; no automatic overwrite of diverged notes.
- Settings UI for manual export, copy and paste import.

## Important limitations
- **Not encrypted:** exported JSON can contain private notes in plain text. Only exchange with trusted devices, do not upload to public storage.
- **Not paired:** there is no Wi-Fi networking, QR pairing, authenticated peer transport or Android integration yet.
- The UI does not show or resolve saved conflicts yet. Inspect `sync_conflicts` or implement review UI before production release.
- Each export starts at cursor zero in the current UI. Idempotence prevents duplicate replay, but a longer running setup must persist per-peer cursors.
- A single bundle is limited to 500 local changes, and import size is capped at 5 MB. Pagination UI is not implemented.
- Imported changes are not re-exported. Multi-hop device syncing is not yet supported.
- Rust/Windows compilation and runtime are unverified.
