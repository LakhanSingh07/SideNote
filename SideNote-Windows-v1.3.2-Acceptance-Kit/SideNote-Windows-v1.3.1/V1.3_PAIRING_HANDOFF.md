# SideNote Windows v1.3 — Verified Manual Pairing

Changes:
- SHA-256 fingerprint of public Ed25519 key, displayed as 8 groups of 4 uppercase hex characters (first 128 digest bits).
- Local fingerprint visible in trusted devices settings.
- Entered peer key fingerprint shown for separate-channel comparison.
- Explicit checkbox required before saving a trusted peer.
- Previously pinned non-empty public keys cannot be overwritten by re-running trust command. Unpair, verify again, and re-pair for rotations.
- Added Rust unit tests for fingerprint formatting and malformed input.

SECURITY WARNING: This is *manual out-of-band fingerprint verification*, not automatic PAKE/QR handshake or secure key exchange. The on-screen confirmation checkbox records no cryptographic proof of a human verification. Existing shared transport secret must be kept private and rotated after device removal. No QR discovery or Android sync.

Validation needed on Windows: `cargo fmt --check`, `cargo test`, `cargo check`, `npm install`, `npm run build`, two-PC wrong-key/legitimate-peer tests and UI fingerprint display. These have not been completed here; no Rust toolchain is available in the build environment.
