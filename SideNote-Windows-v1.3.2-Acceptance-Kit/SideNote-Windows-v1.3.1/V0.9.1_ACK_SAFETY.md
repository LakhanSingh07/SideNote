# SideNote Windows v0.9.1 — Acknowledgement Safety Patch

## Targeted fix

The LAN transport previously trusted a peer-reported acknowledgement cursor without verifying that the acknowledged sequence existed in the local change history. A mistaken or maliciously large cursor could suppress later changes in the export path.

- Reject negative, backward and beyond-available acknowledgements.
- On server reconnect, bound the first acknowledgement by the largest committed local-origin change sequence.
- For later exchanges, bound the acknowledgement by the last outgoing page sequence.
- On the client, reject remote acknowledgements beyond the last locally exported page.
- Add a regression test for accepted, backward, negative and future acknowledgements.

## Validation limits

Source inspection and archive checks only. No Rust or Tauri compilation performed. The current pairing key is manually shared and lacks approved device enrollment, expiration, revocation, and user-facing mutual confirmation. Do not expose TCP port 43861 to the public internet. Android sync is not implemented.
