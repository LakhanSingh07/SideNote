# SideNote Windows v1.2 — DPAPI identity protection

## Changed
- Device signing seed stored as `identity_seed_dpapi_v1` protected by Windows user-scoped DPAPI.
- Upgrade migrates previous `identity_seed` plaintext value while preserving the public key.
- Identity reads for display and LAN handshake use DPAPI-unprotected value.
- Rust Windows-only tests supplied for creation, reload, and legacy migration.

## Important limits
- No Rust compiler or Windows runtime was available in the build environment; source has not compiled or run on Windows. Validate with `cargo test`, `cargo check`, Tauri build, and two-device sync on Windows.
- Windows DPAPI user-scope does not protect secrets from malware running as the signed-in user.
- Deleted plaintext SQLite values may remain in WAL, filesystem snapshots, backup copies, or unallocated pages; this migration does not promise secure erasure. Protect existing database copies and rotate device identity if compromise is suspected.
- Windows-only identity storage: this DPAPI-specific build does not support running the backend on Linux/macOS.
- Pairing remains manual public-key pinning. QR/verification code, discovery, key rotation/revocation, and cross-platform sync pending.
