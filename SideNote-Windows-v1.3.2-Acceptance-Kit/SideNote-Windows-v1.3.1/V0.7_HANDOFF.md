# SideNote Windows v0.7 — Conflict Review Source

## Added
- Native `list_sync_conflicts` command to list unresolved incoming edits.
- Native `resolve_sync_conflict` command with two explicit choices: keep local version, or save incoming upsert as an independent note.
- Conflict review UI under Settings > Offline transfer.
- Resolution and copy creation executed atomically with SQLite transactions.

## Not yet implemented
- No automatic LAN discovery or secure pairing.
- No encryption for manual JSON bundles.
- No network transport.
- No Android integration.
- Native Windows app has not been compiled or runtime-tested.

## Critical follow-on work
1. Secure device pairing: mutual approval and verified public-key fingerprints.
2. Authenticated encrypted LAN transport; replay prevention and limits.
3. Per-peer incremental sync cursors; propagate imported changes safely without loops.
4. Android migration, change tracking and compatible schema.
5. Build, two-device integration testing and real Windows UI screenshots.

## Test cases for Antigravity
- Import bundle from device A; ensure changes added.
- Import exact same bundle again; no duplicate notes/conflicts.
- Edit same ID on both devices; import remote change; local survives, conflict displayed.
- Save incoming as copy; both versions present with different IDs.
- Keep local; local content unchanged.
- Remote deletion conflicts offer Keep Local only.
- Restart app and review unresolved conflicts persists.
- Try malformed payload, repeated imports, and database failures.
