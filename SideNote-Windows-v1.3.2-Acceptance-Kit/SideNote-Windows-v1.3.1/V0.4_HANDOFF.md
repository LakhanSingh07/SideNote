# SideNote Windows v0.4 — desktop integration source

## Added
- Tauri global shortcut plugin registered by main manager window; Ctrl+Shift+N creates a note, Ctrl+Shift+E opens the edge deck through the manager. If the manager webview is destroyed, shortcuts will not run.
- Autostart settings toggle (Windows login) through official Tauri autostart plugin. Default off.
- Closing the main manager hides it in the tray; Quit SideNote from tray terminates app.
- Explicit limitations in Settings and error message for shortcut registration failure.

## Still needed before release
- Windows compile and plugin API/capability verification; no Rust toolchain available in this environment.
- Verify tray persistence after close, startup toggle across reboot and shortcut collisions on Windows 10 and 11.
- Edge window currently uses right-edge geometry and is not dockable to arbitrary monitor edges; multimonitor/HIDPI validation required.
- Hover animation, native window state restoration and note editing lifecycle need actual running desktop acceptance.
- Local P2P sync not implemented. Both platforms remain standalone.

## Windows test matrix
1. npm install; npm run build; npm run tauri build.
2. Open manager; create/edit note; hover edge deck; drag note.
3. Close manager: tray must remain; open via tray; quit must exit.
4. Toggle Windows startup; sign out and back in; verify boot only when enabled.
5. Test both global shortcuts while Chrome/Explorer focused; check unavailable shortcut diagnostics.
6. Test scaling 100%, 125%, 150%, primary/secondary monitors, replug monitor and lock/unlock.
7. Check note persistence across normal restart and abrupt termination.
